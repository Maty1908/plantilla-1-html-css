# Landing Page - The Odin Project

Una página de aterrizaje moderna desarrollada como parte del plan de estudios de **The Odin Project**. Este proyecto está enfocado en practicar y consolidar los fundamentos de **HTML5** y **CSS3**, utilizando **Flexbox** para la maquetación y alineación de elementos.

## 🛠️ Tecnologías Utilizadas

* **HTML5** (Estructura semántica)
* **CSS3** (Estilos y maquetación)
* **Flexbox** (Distribución y alineación de elementos)
* **Google Fonts** (Tipografía Roboto)
